1. Prerequisites

Verification of the following environment settings is required for a successful build:

  • JDK 17 Required
  • Android Studio Ladybug (2024.2.1+)
  • Min SDK: API 24, Target SDK: 35, Compile SDK: 36

2. API & Required Parameters

To initialize the SDK, you must provide the following required payload values:

● phoneNumber: User mobile number (without +).
● countryCode: Example: +91, +966.
● environment: development or production.
● language: en or ar.
● authCode: Generated from the authentication API (expires in 5 minutes).
● partnerUserId: Unique identifier for the partner user.
Validation Rule: SDK accepts only development or production in environment. Any other value will fail initialization.

6. Launching the SDK

Use the SDK native facade helper (SgTravelNative). Do not implement MethodChannel wiring directly in partner app.

Testing Credentials:
Use the following details for your sandbox environment:

phoneNumber: 554433223
countryCode: +966
auth_code (API): Generate using the authentication API endpoint below

Note: You must call the auth code generation API before initializing the SDK, and generate a fresh auth code on each Booking/Order tap. partnerUserId: 2

Authentication Flow:

To enable user login via auth code (without OTP verification), follow the steps below:

  • Step 1: Generate Auth Code
    Call the ShoppingGate API from your backend to generate an auth code. This auth code is required for silent login without OTP verification and should be regenerated for each Booking/Order flow launch. Use the same device_id source used by SDK login (Android example: Build.ID, fallback to ANDROID_ID).
    API Request
    curl -X 'POST' \
  'https://microservices.shoppinggate.app/users/users/sdk/generate-auth-code' \
  -H 'accept: */*' \
  -H 'Content-Type: application/json' \
  -d '{
  "host_id": "barq",
  "host_secret": "barq-*****",
  "phone_number": "*********",
  "phone_code": "****",
  "device_id": "deviceId",
  "partnerUserId": "unique_partner_user_id"
}'
    API Response
    {
  "status": true,
  "message": "Auth code generated successfully",
  "data": {
    "auth_code": "******************",
    "expires_in": 300
  }
}
  • Step 2: Pass Auth Code to SDK
    Once you receive the auth_code from the API response, pass it to the SDK during initialization using the authCode field. The SDK will perform a silent login without requiring OTP verification. (auth_code is API key, authCode is SDK request key)
    Kotlin Example
    SgTravelNative.initialize(
    request = SgTravelNative.SgTravelRequest(
        phoneNumber = "*********",
        countryCode = "****",
        environment = "development",
        language = "en",
        authCode = "******************", // Fresh code from API response
        partnerUserId = "unique_partner_user_id" // Unique identifier for the partner user
    )
)
    Note: The auth code expires in 300 seconds (5 minutes). Always fetch a new auth code before each openBooking/openOrder action.

A. Google Maps API Key Required

The SDK uses Google Maps to display location-based screens. Maps will not load without a valid API key. Add the following <meta-data> entry inside the <application> tag of your android/app/src/main/AndroidManifest.xml.

This step is not optional. If the Maps API key is missing or invalid, all map screens inside the SDK will fail to render. Ensure the key is enabled for the Maps SDK for Android in your Google Cloud Console and is restricted to your app's package name and SHA-1 fingerprint.
android/app/src/main/AndroidManifest.xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <application>

        <!-- ✅ REQUIRED: Replace with your actual Google Maps API key.
             Maps screens inside the SDK will NOT load without this.
             Generate your key at: https://console.cloud.google.com/
             Enable: Maps SDK for Android
             Restrict to: your app package name + SHA-1 fingerprint -->
        <meta-data
            android:name="com.google.android.geo.API_KEY"
            android:value="REPLACE_YOUR_MAP_KEY_HERE"/>

        <!-- ... rest of your manifest ... -->

    </application>
</manifest>

B. Theme Configuration Optional

You can customize the SDK's appearance by setting a theme before calling initialize. Use the setTheme(config) method with a ThemeConfig data class to pass your brand colors directly from native code.

● primaryColor  — Primary brand color used for buttons, highlights, and interactive elements. Hex format e.g. "#FF6B35"
● scaffoldBackground  — Background color of the main scaffold/screen. Hex format e.g. "#F5F5F5"
● secondaryColor  — Secondary color used for accents and secondary UI elements. Hex format e.g. "#1D1C1C33"
Important: setTheme must be called before initialize. If not called, the SDK will use its default theme. All color values must be in hex string format (e.g. "#RRGGBB" or "#RRGGBBAA").
Kotlin Example
// Step 1: Set theme before initializing (optional)
SgTravelNative.setTheme(
    SgTravelNative.ThemeConfig(
        primaryColor = "#090909",
        scaffoldBackground = "#0B8085",
        secondaryColor = "#1D1C1C33"
    )
)

// Step 2: Initialize as usual
SgTravelNative.initialize(request = SgTravelNative.SgTravelRequest(...))

C. Native Facade Helper

SgTravelNative.kt
package com.sg.travelsdkdemo

import android.app.Activity
import android.content.Context
import android.content.Intent
import android.os.Handler
import android.os.Looper
import android.util.Log
import io.flutter.FlutterInjector
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.embedding.engine.FlutterEngineCache
import io.flutter.embedding.engine.dart.DartExecutor
import io.flutter.plugin.common.MethodCall
import io.flutter.plugin.common.MethodChannel
import java.lang.ref.WeakReference

object SgTravelNative {
    const val CHANNEL_NAME: String = "shoppingate_travel_sdk/channel"
    private const val ENGINE_ID: String = "sg_travel_sdk_engine"
    private const val TAG: String = "SGTravelNative"

    const val METHOD_INITIALIZE: String = "initialize"
    const val METHOD_OPEN_BOOKING_FLOW: String = "openBookingFlow"
    const val METHOD_OPEN_ORDER_FLOW: String = "openOrderFlow"

    const val METHOD_HOST_READY: String = "hostReady"
    const val METHOD_SET_USER_DATA: String = "setUserData"
    const val METHOD_CLOSE_SDK: String = "closeSDK"
    const val METHOD_CONTINUE_TO_PAYMENT: String = "continueToPayment"
    private const val METHOD_INVOKE_PAYMENT: String = "invokePaymentInitiation"

    private const val KEY_PHONE = "phoneNumber"
    private const val KEY_COUNTRY = "countryCode"
    private const val KEY_ENV = "environment"
    private const val KEY_LANG = "language"
    private const val KEY_AUTH_CODE = "authCode"
    private const val KEY_PARTNER_USER_ID = "partnerUserId"

    private const val KEY_PRIMARY_COLOR = "primaryColor"
    private const val KEY_SCAFFOLD_BACKGROUND = "scaffoldBackground"
    private const val KEY_SECONDARY_COLOR = "secondaryColor"

    private val lock = Any()
    private val mainHandler = Handler(Looper.getMainLooper())
    private var latestData: MutableMap<String, Any> = mutableMapOf()
    private var isInitialized = false
    private var isFlutterReady = false
    private var shouldDestroyEngineOnHostDestroy = false
    private var methodChannel: MethodChannel? = null
    private val pendingCalls: MutableList<ChannelCall> = mutableListOf()
    private var hostActivityRef: WeakReference<Activity>? = null
    private var pendingThemeConfig: ThemeConfig? = null

    private data class ChannelCall(
        val method: String,
        val arguments: Any?,
        val callback: MethodChannel.Result? = null,
    )

    data class SgTravelRequest(
        val phoneNumber: String,
        val countryCode: String,
        val environment: String,
        val language: String,
        val authCode: String,
        val partnerUserId: String,
    )

    data class ThemeConfig(
        val primaryColor: String,
        val scaffoldBackground: String,
        val secondaryColor: String,
    )

    @JvmStatic
    fun initialize(request: SgTravelRequest) {
        initialize(request = request, callback = null)
    }

    @JvmStatic
    fun setTheme(config: ThemeConfig) {
        synchronized(lock) {
            pendingThemeConfig = config
        }
    }

    @JvmStatic
    fun initialize(request: SgTravelRequest, callback: MethodChannel.Result?) {
        val normalized = normalizeRequest(request)
        val authCode = normalized[KEY_AUTH_CODE]?.toString().orEmpty()
        Log.d(TAG, "initialize dispatch authCodeLength=${authCode.length}")

        synchronized(lock) {
            pendingThemeConfig?.let { theme ->
                normalized[KEY_PRIMARY_COLOR] = theme.primaryColor
                normalized[KEY_SCAFFOLD_BACKGROUND] = theme.scaffoldBackground
                normalized[KEY_SECONDARY_COLOR] = theme.secondaryColor
            }
            latestData = normalized
            isInitialized = true
        }

        dispatchOrQueue(METHOD_INITIALIZE, HashMap(normalized), callback)
    }

    @JvmStatic
    fun warmUpEngine(context: Context) {
        ensureEngineStarted(context)
    }

    @JvmStatic
    fun openBooking(context: Context) {
        ensureInitialized()
        val createdNewEngine = ensureEngineStarted(context)
        if (createdNewEngine) dispatchInitialize()
        launchHost(context)
        dispatchOrQueue(METHOD_OPEN_BOOKING_FLOW, null)
    }

    @JvmStatic
    fun openOrder(context: Context) {
        ensureInitialized()
        val createdNewEngine = ensureEngineStarted(context)
        if (createdNewEngine) dispatchInitialize()
        launchHost(context)
        dispatchOrQueue(METHOD_OPEN_ORDER_FLOW, null)
    }

    @JvmStatic
    fun onHostActivityDestroyed(activity: Activity) {
        val shouldReset = synchronized(lock) {
            val host = hostActivityRef?.get()
            if (host == activity) {
                hostActivityRef = null
                shouldDestroyEngineOnHostDestroy = false
                return@synchronized true
            }
            val pending = shouldDestroyEngineOnHostDestroy
            shouldDestroyEngineOnHostDestroy = false
            pending
        }

        if (shouldReset) resetEnginePreservingInitialization()
    }

    private fun dispatchOrQueue(
        method: String,
        arguments: Any?,
        callback: MethodChannel.Result? = null,
    ) {
        val activeChannel = synchronized(lock) {
            if (methodChannel == null || !isFlutterReady) {
                pendingCalls.add(ChannelCall(method, arguments, callback))
                null
            } else {
                methodChannel
            }
        }

        if (activeChannel != null) {
            invokeMethodOnMainThread(activeChannel, method, arguments, callback)
        }
    }

    private fun invokeMethodOnMainThread(
        channel: MethodChannel,
        method: String,
        arguments: Any?,
        callback: MethodChannel.Result? = null,
    ) {
        if (Looper.myLooper() == Looper.getMainLooper()) {
            if (callback != null) channel.invokeMethod(method, arguments, callback)
            else channel.invokeMethod(method, arguments)
            return
        }

        mainHandler.post {
            if (callback != null) channel.invokeMethod(method, arguments, callback)
            else channel.invokeMethod(method, arguments)
        }
    }

    private fun normalizeRequest(request: SgTravelRequest): MutableMap<String, Any> {
        return mutableMapOf(
            KEY_PHONE to request.phoneNumber,
            KEY_COUNTRY to request.countryCode,
            KEY_ENV to request.environment,
            KEY_LANG to request.language,
            KEY_AUTH_CODE to request.authCode,
            KEY_PARTNER_USER_ID to request.partnerUserId,
        )
    }

    // ... Keep remaining helper methods same as project source (attachChannel,
    // ensureEngineStarted, handleMethodCall, parsePaymentPayload, destroy, etc.)
}

D. Create Flutter Activity

SgFlutterActivity.kt
package com.sg.travelsdkdemo

import io.flutter.embedding.android.FlutterActivity

/**
 * A thin [FlutterActivity] subclass that keeps [SgTravelNative] aware of the
 * currently visible host activity.
 *
 * This allows [SgTravelNative] to:
 *  - Properly call [finish] when the SDK requests `closeSDK`.
 *  - Start the native [PaymentActivity] when the SDK requests `continueToPayment`.
 */
class SgFlutterActivity : FlutterActivity() {

    override fun onResume() {
        super.onResume()
        SgTravelNative.setHostActivity(this)
    }

    override fun onDestroy() {
        super.onDestroy()
        SgTravelNative.onHostActivityDestroyed(this)
    }

    companion object {
        fun withCachedEngine(engineId: String): CachedEngineIntentBuilder =
            CachedEngineIntentBuilder(SgFlutterActivity::class.java, engineId)
    }
}

E. Host Activity Usage

MainActivity.kt
private enum class SdkFlowType { BOOKING, ORDER }

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        findViewById<Button>(R.id.openBooking).setOnClickListener {
            loginAndOpenFlow(SdkFlowType.BOOKING)
        }

        findViewById<Button>(R.id.openOrder).setOnClickListener {
            loginAndOpenFlow(SdkFlowType.ORDER)
        }
    }

    private fun loginAndOpenFlow(flowType: SdkFlowType) {
        Thread {
            val authCode = fetchAuthCodeFromApi() // call API every tap
            runOnUiThread { initializeSdkAndOpen(authCode, flowType) }
        }.start()
    }

    private fun initializeSdkAndOpen(authCode: String, flowType: SdkFlowType) {
        SgTravelNative.warmUpEngine(this)

        SgTravelNative.setTheme(
            SgTravelNative.ThemeConfig(
                primaryColor = "#090909",
                scaffoldBackground = "#0B8085",
                secondaryColor = "#1D1C1C33"
            )
        )

        SgTravelNative.initialize(
            request = SgTravelNative.SgTravelRequest(
                phoneNumber = "554433223",
                countryCode = "+966",
                environment = "development",
                language = "en",
                authCode = authCode,
                partnerUserId = "2"
            ),
            callback = object : MethodChannel.Result {
                override fun success(result: Any?) {
                    when (flowType) {
                        SdkFlowType.BOOKING -> SgTravelNative.openBooking(context = this@MainActivity)
                        SdkFlowType.ORDER -> SgTravelNative.openOrder(context = this@MainActivity)
                    }
                }

                override fun error(code: String, message: String?, details: Any?) {
                    Toast.makeText(this@MainActivity, "Init error: ${message ?: code}", Toast.LENGTH_LONG).show()
                }

                override fun notImplemented() {
                    Toast.makeText(this@MainActivity, "Init error: method not implemented", Toast.LENGTH_LONG).show()
                }
            },
        )
    }

    override fun onDestroy() {
        super.onDestroy()
        SgTravelNative.destroy()
    }
}

G. Payment Screen Logic

PaymentActivity.kt
package com.sg.travelsdkdemo

import android.content.Context
import android.content.Intent
import android.os.Bundle
import android.widget.Button
import android.widget.ImageView
import android.widget.TextView
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity

/**
 * Native payment screen shown when the Travel SDK invokes `continueToPayment`.
 *
 * Displays the booking amount and lets the user initiate payment. On confirming,
 * it calls [SgTravelNative.invokePaymentInitiation] to signal back to the SDK.
 */
class PaymentActivity : AppCompatActivity() {

    private var isPaymentInitiated = false

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_payment)

        val amount = intent.getDoubleExtra(EXTRA_AMOUNT, 0.0)
        val orderId = intent.getStringExtra(EXTRA_ORDER_ID)

        val tvAmount = findViewById(R.id.tvAmount)
        val btnPay = findViewById(R.id.btnPay)
        val btnClose = findViewById(R.id.btnClose)

        tvAmount.text = getString(R.string.payment_amount_label, amount)

        btnPay.setOnClickListener {
            if (!isPaymentInitiated) {
                isPaymentInitiated = true
                btnPay.isEnabled = false
                btnPay.text = getString(R.string.payment_initiated_label)
                val transactionId = buildTransactionId(orderId)
                SgTravelNative.invokePaymentInitiation(transactionId)
                // Automatically close the payment screen after payment initiation
                btnClose.postDelayed({ finish() }, 300)
            }
        }

        btnClose.setOnClickListener {
            finish()
        }
    }

    companion object {
        private const val EXTRA_AMOUNT = "extra_amount"
        private const val EXTRA_ORDER_ID = "extra_order_id"
        private const val EXTRA_REQUEST_PAYMENT_TYPE = "extra_request_payment_type"

        fun newIntent(
            context: Context,
            amount: Double,
            orderId: String?,
            requestPaymentType: String?,
        ): Intent =
            Intent(context, PaymentActivity::class.java)
                .putExtra(EXTRA_AMOUNT, amount)
                .putExtra(EXTRA_ORDER_ID, orderId)
                .putExtra(EXTRA_REQUEST_PAYMENT_TYPE, requestPaymentType)

        private fun buildTransactionId(orderId: String?): String {
            val timestamp = System.currentTimeMillis()
            return if (!orderId.isNullOrBlank()) {
                "TXN_${orderId}_$timestamp"
            } else {
                "TXN_$timestamp"
            }
        }
    }
}

7. Troubleshooting

  • Initialize First: Call initialize before openBooking/openOrder.
  • Environment Validation: Use only development or production.
  • No Direct MethodChannel: Keep partner app on SgTravelNative facade API only.
  • Maps Issues: Ensure API key is enabled for Maps SDK and restricted with package/SHA.
